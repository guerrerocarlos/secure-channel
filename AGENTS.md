# Secure Channel Workspace

This repository is a client-side encrypted-channel application.

- Never commit private keys, seed phrases, plaintext conversations, production credentials, or encrypted-user data.
- Treat changes to cryptography, key handling, authentication, and message delivery as security-sensitive and require explicit review.
- Maintain `docs/agent/STATE.md`, `RUNBOOK.md`, `DECISIONS.md`, and `LINKED_REPOS.md` as the operational context evolves.
